## English

**A fan-made remaster of the classic mobile game Wolf Moon (2006), created by PilotOfAsuka together with Codex AI.**

Remember Wolf Moon on your old Java phone? The forests, werewolves, Wendigo totems, and Janet Cain’s story return to a bigger screen. We preserve the original’s familiar pixel-art atmosphere while making it more comfortable to play, with a widescreen view, a larger interface, and keyboard and mouse controls.

For returning fans, anyone who has been searching for this game, and those discovering Wolf Moon for the first time. Follow the link above and play right in your browser — no installation needed.

**Controls:** WASD / arrows — move and turn · Q / E — items · I — inventory · Enter / Space — act · R — rest · M — map · J — journal · Esc — menu · F2 — switch between original and widescreen views.
