# Разработка и проверки Wolf Moon

**[▶ Играть в браузере](https://pilotofasuka.github.io/wolf-moon-remastered/)** · [Исходники Godot](game/project.godot)

Скачивание и установка игры не нужны. В репозитории находится исходный Godot-проект; JAR и исследовательские материалы в него не входят.

Wolf Moon 1.06 с широким классическим видом: исходная пиксельная графика, сохранённые пропорции спрайтов, плотная трава и повторяющийся дальний фон. **F2** плавно переключает исходный экран и широкий вид, сохраняя текущее состояние игры.

## Управление

| Действие | Управление |
|---|---|
| Движение и повороты | WASD / стрелки |
| Выбрать предмет | Мышь на нижней панели или Q / E |
| Использовать предмет / закрыть сообщение | Enter / Пробел |
| Спать, восстановить силы и сохранить игру | Кнопка «Спать» или R |
| Карта на весь игровой экран | M / кнопка «Карта» |
| Журнал | J / кнопка «Журнал» |
| Меню / назад | Esc |
| Переключить вид | F2 |
| Быстро сохранить / загрузить | F5 / F9 |

Отдых доступен при исходных условиях игры. Горящая печь и костёр дают исходный бонус к восстановлению сил. Сон сохраняет игру автоматически. Язык кнопок соответствует языку, выбранному в игре.

Сохранения хранятся в браузере для этого адреса. Для продолжения используй тот же браузер; очистка данных сайта удаляет сохранения.

## Проект

Игра запускается в WebGL 2 без Java и без загрузки JAR пользователем. Исходная логика исполняется переносимым GDScript-ядром совместимости. Правила боя, ИИ, карты и сюжета сохранены из предоставленного оригинала.

Для разработки: Godot **4.7.2**, проект `game/project.godot`. Web — единственный пресет экспорта. Исходники находятся в ветке `godot`, готовый экспорт — в `web-build`. GitHub Pages публикует корень `web-build`. Подробнее — [GitHub и Web](docs/GITHUB_WEB.md).

## Проверки

- 15 независимых сценариев на оригинальной JVM, 1431 сравнение без различий.
- Четыре сцены: ускоренный исходный рендер совпадает с исходными пикселями, состоянием и генератором случайных чисел.
- Сон через настоящую кнопку: горящая и погашенная печь, горящий и погашенный костёр, время, выносливость и исходное автосохранение на 2600 байт.
- Крупный интерфейс в 4K, труп выше нижней панели, значки персонажей и огня, большая карта, RU/EN и подсказки для клавиатуры.
- Web: новая игра, движение, F2, сохранение, перезагрузка страницы и F9.

Полное прохождение всех концовок ещё не подтверждено. Фактический объём проверок — в [PROGRESS.md](PROGRESS.md), оставшиеся проверки — в [REMAINING_WORK.md](REMAINING_WORK.md).
